# Зона: Первый выход

Офлайн-прототип 3D FPS на Godot 4 для Android.

## Что уже есть
- Небольшая промышленная зона с укрытиями и ограждением.
- Вид от первого лица и простая модель пистолета.
- Три противника, которые преследуют игрока и наносят урон вблизи.
- Стрельба лучом, магазин на 12 патронов и запас боеприпасов.
- Сенсорный джойстик, управление обзором правой частью экрана, кнопки FIRE и RELOAD.
- Индикаторы здоровья, патронов и оставшихся целей.
- Игра работает без подключения к интернету после установки.

## Облачная сборка
GitHub Actions запускает сборку при каждом push в ветку main или вручную через вкладку Actions. Если сборка прошла успешно, APK доступен в артефактах соответствующего запуска.

Это ранний прототип: визуальная часть и баланс требуют дальнейшего тестирования на реальном телефоне.
